# SegScope 技术设计

## 处理流程

1. 浏览器将主图像、辅助模态和 ROI 作为 JSON 发送到 `/api/segment`。
2. 服务端将长边限制在 512 像素，降低内存和延迟波动。
3. OpenCV Lab 快速模式或 GrabCut 精细模式根据 ROI 生成主图像二值掩膜。
4. 辅助模态完成高斯平滑、归一化和方向判断，形成辅助概率图。
5. 主掩膜与辅助概率图按用户权重融合，并进行闭运算和开运算。
6. 服务端输出单模态掩膜、融合掩膜、叠加图和运行指标。

## 接口

### POST /api/segment

请求字段：

- `image`：主图像 Data URL，必填。
- `auxiliary`：辅助模态 Data URL，可选。
- `roi`：原图坐标 `[x, y, width, height]`，可选。
- `iterations`：GrabCut 迭代次数，范围 1 到 10。
- `fusionWeight`：辅助模态权重，范围 0 到 0.85。

响应包括结果 PNG、输入尺寸、处理管线和指标。

## 异常处理

- 拒绝空请求和超过 24 MB 的请求。
- 对 ROI 进行边界裁剪，避免越界。
- 主图像无法产生有效前景时退回 ROI 掩膜，保证 Demo 有可观察输出。
- 辅助模态自动缩放到主图尺寸。
