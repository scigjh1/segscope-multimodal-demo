# 开源与私有内容边界

| 公开发布 | 保留私有 |
|---|---|
| 通用交互界面、图像处理与指标代码 | 医院原始影像、标注、病例信息、DICOM 元数据 |
| 自己编写的工具代码、测试与合成样例 | 未公开研究模型、训练配方、模型权重与实验原始日志 |
| 本地运行说明、可复现的合成样例协议 | 基金申请书、合作协议、未公开课题材料 |
| 通用模块接口与依赖来源 | SSH 账号、密码、地址、密钥、内部服务配置 |

本仓库只发布经过逐文件选择的通用 Demo 文件。合成图像和掩膜由生成脚本产生，不来自患者。真实数据即便脱敏，也应在确认使用权限后留在适合的私有环境中。

如果需要接入研究模型，把模型实现、权重和数据放在仓库外的私有目录；不要放在 static 下或随截图提交。此仓库的开源许可只覆盖本仓库发布的代码，不授予医院、合作机构、数据集或其他研究成果的权利。
